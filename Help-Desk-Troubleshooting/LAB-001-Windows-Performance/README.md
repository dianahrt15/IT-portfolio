# LAB-001: Windows Performance Troubleshooting

## 1. Overview
**Category:** Help Desk / Windows Troubleshooting

**Environment:** Windows 11 Virtual Machine

**Tool:** Task Manager

## 2. Objective
Investigate a report of slow computer performance by monitoring CPU, memory, and disk usage.

## 3. Scenario
A user reports that their computer is running slowly.

As a Service Desk Analyst, I need to investigate system resource usage and determine whether the performance issue can be reproduced.
